# welldom-player

A blank YouTube player page for the WellDom app's Video window. YouTube only plays embedded videos on pages with a web address, and WellDom runs from a file on the phone, so the app shows this page (served by GitHub Pages) instead.

`https://dtneary.github.io/welldom-player/#v=<video id>&s=<start seconds>` or `#list=<playlist id>&i=<index>&s=<seconds>`.

It stores nothing. It tells the app where playback is (so the next session resumes there) and accepts play/pause from it.
